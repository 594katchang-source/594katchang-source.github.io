# 2026-10-11 體智遊戲「活動影片資料庫 (`teach/activity-database/`)」整合與全站優化專案

## 1. 專案目標與架構定位
- **全齡跨世代定位**：在 `teach/`（衛教工具與教學遊戲）的「**3. 體智遊戲**」分類下，全新建置 **[活動影片資料庫](../../teach/activity-database/index.html)**，將四大參考資料庫共 **239 筆**活動影片與教案靈感完整統合於單一頁面，並將引導語、核心目的與退階/進階調整全面擴展至**全年齡層**（親子/兒童、青少年/校園、成人/企業團建紓壓、樂齡/社區長輩與失智友善）。
- **日照活動頻道庫無縫打散**：不設置獨立「頻道庫切換按鈕」，直接將原《日照活動靈感庫》的 30 筆國內外精選頻道依其主要活動屬性打散歸入三大主分類（藝術創作、手工教案、團康活動）。

## 2. 資料庫統計與結構（共 239 筆，100% YouTube oEmbed 驗證通過）
- **第一層主分類導覽分頁 (`#catChips`)**：
  - `全部活動 (239)`
  - `🎨 藝術創作 (41)`：原《教案靈感庫》40 筆 ＋ 原《日照活動靈感庫》美術創作類 1 筆
  - `🧶 手工教案 (131)`：原《手工藝教案資料庫》124 筆 ＋ 原《日照活動靈感庫》手作/園藝/節慶類 7 筆
  - `🎲 團康活動 (67)`：原《派對遊戲資料庫》45 筆 ＋ 原《日照活動靈感庫》體能/認知/音樂/團體遊戲類 22 筆
- **第二層收合式進階篩選 (`▾ 更多跨庫篩選`)**：
  - 完整收納原四大網站所有細部分類（共 7 大維度、88 個細分篩選膠囊，經 `audit_verification.py` 驗證 100% 皆有對應資料、零空集合）。
- **彈窗結構與底部四大行動按鈕**：
  - 統一對齊 `exercise-database/` 的 5 大結構化色塊（🎯 活動訓練目的與能力效益、🧰 準備材料道具與環境設置、📋 活動步驟與玩法規則拆解、⚠️ 安全與帶領提醒、🔄 全齡退階與進階調整），100% 保留原四大網站彈窗內文並預先完成全齡 AI 結構化增補。
  - 底部行動按鈕：`▶ 看影片跟著做`、（團康活動額外提供 `🔍 延伸玩法規則搜尋 ↗`）、`📋 複製 AI 延伸提問`、`🖨️ 列印單張教案`。

## 3. 目錄結構與交付清單
- `source/`：四大參考網站原始 HTML 備份（`daycare-activity-library.html`, `seniorart.html`, `party-games.html`, `art-senior-database.html`）
- `extract_and_verify.py`：解析 239 筆原始資料並透過 YouTube oEmbed API 100% 驗證真實影片 ID 與縮圖（產出 `verified_raw_239.json`）
- `generate_activities_json.py`：轉換並生成全齡結構化資料庫 `activities_full.json`
- `build_activity_html.py`：生成 `teach/activity-database/index.html`
- `audit_verification.py`：交付前三點式自我審查（首項、中項、末項）與 92 顆篩選膠囊完整性驗證腳本
- `output/`：最終交付成品備份（`index.html`, `activities_full.json`）
