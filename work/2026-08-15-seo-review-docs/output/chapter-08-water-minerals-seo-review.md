# 正文

## 每天喝多少水才夠？從電解質、鈣鐵到骨質保養

本篇整理書籍：《Nutrition Concepts & Controversies》第 17 版
本篇章節：Chapter 8，Water and Minerals（水與礦物質）
文章性質：依原章節概念順序整理，加入台灣生活情境、營養師判讀與現行資料查核。本篇為待審稿。

省時版本：很多人把喝水簡化：每天 2000 ml、尿液越透明越好、運動一定要喝運動飲料。礦物質也常被簡化成「累就補鐵」「抽筋就補鎂」「骨質疏鬆就補鈣」。這些說法都少了重要的判讀：身體需要的是水分與電解質的平衡，營養素需要配合年齡、飲食、活動量、疾病、藥物與檢驗結果。

水分是日常維持循環、體溫、排便與身體功能的基礎。先看口渴、尿液、活動、天氣與疾病，再分辨一般飲水、流失過多、電解質失衡與醫師交代限水的情況。食物也能提供水分與礦物質，補充品和運動飲料不能取代對症處理。從了解水分平衡與脫水開始，接著認識電解質與巨量礦物質、鈣鐵等礦物質的功能，再回到三餐中分析鈣來源、飲食安排、補充品與就醫警訊。

## 水在身體裡做什麼？

水約占成人體重的一半以上，分布在血液、細胞內外與各種組織。它負責運送營養物質與代謝產物，協助食物消化與化學反應，讓關節、眼睛與黏膜維持潤滑，也透過血液循環、皮膚與汗液參與散熱。腎臟則會依照身體狀況調整尿液濃度與排出量。

飲水量會隨情境改變。高溫、濕熱、長時間戶外活動、發燒、嘔吐、腹瀉、吃較多鹽分或纖維、懷孕與哺乳，都可能改變需要。水果、蔬菜、湯、牛奶、豆漿與其他食物也含有水分，因此討論「一天喝多少」時，要先確認是在說飲品量，或是食物與飲品的總水分。國民健康署的衛教資料提供健康成人每日飲用 6 至 8 杯水、每杯 240 ml 的生活化建議，也提醒要隨活動與環境調整，分次、小口飲用。這是一個日常起點建議，不適用於心臟衰竭、腎臟病、肝硬化、使用利尿劑或醫師交代限水的人身上。[國民健康署：清涼消暑，聰明喝水](https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=4306&pid=14493)

## 礦物質怎麼分類？巨量礦物質與微量礦物質

書中把每天需要量超過 100 mg 的鈣、氯、鎂、磷、鉀、鈉與硫酸鹽歸為巨量礦物質，低於 100 mg 的碘、鐵、鋅、硒、氟、鉻、銅、錳與鉬等歸為微量礦物質。這是分類用語，微量礦物質的生理作用仍很具體。

### 口渴、尿液顏色與脫水，怎麼看？

口渴是身體調節水分的訊號，卻會受到年齡、工作環境、藥物與疾病影響。高齡者的口渴感可能變弱，等到口乾才喝，常已經落後身體需求。尿液顏色可作為生活觀察線索，但可能會受維生素、藥物、食物與泌尿道問題影響。只用一個訊號做判斷，容易誤判。

| 生活觀察 | 可能提示 | 實際做法 |
| --- | --- | --- |
| 口乾、頭痛、疲倦、尿量變少 | 水分攝取不足或其他健康問題 | 先在安全情況下分次補充，持續或加重就求助 |
| 炎熱環境大量流汗 | 水與鈉等電解質一起流失 | 依活動時間、流汗量與醫療建議補水，不要一次灌完 |
| 尿色很淡但頻繁大量飲水 | 可能喝得超過需要 | 暫停追求透明尿，回到口渴、尿量、活動與疾病條件 |
| 尿色突然深、合併發燒或腹瀉 | 可能有脫水或其他病因 | 不用顏色自我診斷，必要時就醫檢查 |
| 高齡、失智、吞嚥困難或臥床 | 口渴與自行取水能力可能不足 | 由照顧者安排白天分次飲水，依吞嚥與限水計畫執行 |

出現意識混亂、昏厥、抽搐、幾乎沒有尿、持續嘔吐、無法進水、嚴重腹瀉或疑似中暑時，問題已經超出一般飲水技巧可以處理的範圍，需要迅速接受醫療評估。這時不能只靠白開水自行補充，因為原因可能涉及嚴重脫水、電解質失衡、感染、心腎肝疾病或其他急症，補水方式與速度應由醫療團隊判斷。

## 水喝太少與喝太多都可能出問題

水分不足會讓循環、體溫調節、腎臟排泄與運動表現受影響。高溫活動時，汗液會帶走水分與鹽分，單純補大量白水未必能處理全部問題。相反地，短時間喝下遠超身體排出能力的水，也可能稀釋血液中的鈉，造成低鈉血症與神經症狀。MedlinePlus 將脫水、過度補水、嘔吐腹瀉、大量流汗、心肝腎疾病與藥物列為水分及電解質失衡的相關情境。[MedlinePlus：Fluid and Electrolyte Balance](https://medlineplus.gov/fluidandelectrolytebalance.html)

這裡建議的原則是：小口、分次、依情境調整。長時間運動、炎熱工作、反覆腹瀉或嘔吐，可能需要含有適當電解質的補液方式，比例與用法要依產品標示或醫療建議。自行把鹽、糖與水隨意混合，無法確保濃度正確。

## 飲料算不算補水？先看糖、咖啡因、鈉與份量

咖啡、茶、牛奶、豆漿、湯與含糖飲料都能帶來水分，但它們同時帶入熱量、糖、蛋白質、鈉或咖啡因。評估飲料時，我會請個案把瓶身上的「每份」改算成「整瓶」或「整杯」，因為一瓶常有兩份以上。

| 飲品 | 可取之處 | 需要留意 |
| --- | --- | --- |
| 白開水 | 無糖、無熱量，適合日常解渴 | 限水者仍要遵守醫囑 |
| 無糖茶或黑咖啡 | 可提供水分，口味選擇多 | 咖啡因可能影響睡眠、心悸與焦慮，孕期需個別確認 |
| 牛奶或無糖豆漿 | 可同時提供蛋白質，部分產品含鈣 | 看糖量、過敏、乳糖耐受與腎臟病飲食 |
| 運動飲料 | 長時間、高強度流汗時有補糖與電解質的用途 | 久坐、短時間散步或一般口渴時，常帶來多餘糖與鈉 |
| 果汁、手搖飲、汽水 | 口味容易接受 | 液體熱量快，配料與大杯容量會拉高糖量 |
| 酒精飲品 | 屬於社交飲品 | 不能當補水工具，孕期、肝病與部分用藥者應避免 |

國民健康署建議以白開水取代含糖飲料，也提醒非運動者長期飲用運動飲料，可能增加熱量與電解質失衡的負擔。[國民健康署：對抗熱傷害，預防勝於治療](https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=577&pid=10741)

## 電解質是什麼？水分分布為什麼會受溶質影響？

電解質是溶在水或體液中會帶電的礦物質，包括鈉、鉀、氯、鈣、鎂與磷酸鹽等。它們參與水分分布、神經傳導、肌肉收縮、心臟節律、酸鹼平衡與骨骼維持。水分會在不同體液區室之間移動，受到溶液中溶質濃度與離子分布影響，因此水分與電解質要一起判讀。

鈉主要位於細胞外液，鉀主要位於細胞內。兩者都需要，重點在分布與平衡，非追求某一方越低越好。嘔吐、腹瀉、大量流汗、腎臟排泄異常、利尿劑或其他藥物，都可能改變電解質狀態。真正的失衡需要病史、理學評估與血液檢查，抽筋或疲倦單獨出現，無法指向某一種礦物質。

### 鈉和鉀怎麼搭配？外食族先處理隱形鈉

台灣國民健康署目前建議成人每日鈉攝取量限制在 2400 mg 以下，約等於食鹽 6 g。鈉常藏在湯汁、醬油、沙茶醬、滷味、麵線、香腸火腿、泡麵、餅乾、調理包與外食菜餚，不是只靠少吃食鹽、控制食鹽而已。[國民健康署：正確飲食習慣](https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=543&pid=8365&sid=9606)

| 外食情境 | 可執行調整 |
| --- | --- |
| 便當 | 飯菜分開看，醬汁少淋，湯品不喝完 |
| 麵食 | 麵湯少喝，滷味少選加工丸餃，增加蔬菜與蛋白質 |
| 火鍋 | 沾醬減量，少喝湯，選原型食材 |
| 早餐 | 留意火腿、培根、肉鬆、醃菜與濃湯 |
| 零食 | 看每份鈉量與一包實際份量，不用「低脂」推論低鈉 |
| 家中烹調 | 用蒜、蔥、薑、胡椒、醋、檸檬與香草增加風味，醬料先量再加 |

鉀多來自蔬菜、水果、豆類、馬鈴薯、乳品與其他原型食物。這項方向適合許多健康成人，卻不適合直接套到慢性腎臟病、高血鉀、透析，或使用會影響血鉀藥物的人。含鉀鹽、低鈉鹽與鉀補充品，也要先問醫師或營養師。NIH ODS 的鉀資料也提醒，腎功能異常者對鉀的處理能力可能改變。[NIH ODS：Potassium](https://ods.od.nih.gov/factsheets/Potassium-HealthProfessional/)

## 鈣、磷、鎂如何一起支持骨骼與肌肉？

鈣約有很大比例儲存在骨骼與牙齒，也參與神經傳導、肌肉收縮與凝血。磷與鈣共同形成骨骼礦物結構，並參與能量傳遞與細胞膜。鎂則支援許多酵素反應、能量利用、神經與肌肉功能。鈣、鎂、磷的作用彼此相關，但不能把它們當成一組買來就能一次補足。是否需要補充，仍要看飲食、檢驗、疾病與用藥，由專業人員評估。

| 礦物質 | 食物方向 | 判讀提醒 |
| --- | --- | --- |
| 鈣 | 奶類、優格、起司、加鈣豆漿、使用鈣鹽製作的豆腐、小魚連骨、青江菜與芥藍等 | 看標示與份量，菠菜含鈣但草酸會降低可吸收量，仍可吃，別把它當主要鈣來源 |
| 磷 | 肉、魚、蛋、乳品、豆類與穀類 | 天然食物通常來源多，腎臟病者需留意加工食品磷添加物 |
| 鎂 | 深綠色蔬菜、豆類、堅果、種子、全穀與黃豆製品 | 高劑量補充品可能腹瀉，腎功能差者需先評估 |

身體會努力維持血鈣在狹窄範圍，血液中的鈣正常，不代表骨骼的鈣儲備充足。骨骼狀況要依病史、骨密度、骨折風險與相關檢查判讀。NIH ODS 的鈣資料整理了食物來源、吸收、補充品與藥物交互作用，適合做為衛教資料的查核底稿。[NIH ODS：Calcium](https://ods.od.nih.gov/factsheets/Calcium-HealthProfessional/)

## 鐵不足會疲倦嗎？先找原因再補充

鐵參與血紅素、肌紅蛋白與多種酵素功能。缺鐵性貧血可能帶來疲倦、頭暈、心悸、臉色變淡、活動耐受變差或注意力下降，但疲倦也可能來自睡眠不足、熱量攝取少、甲狀腺問題、感染、慢性病、壓力或其他營養素不足。

含血基質鐵的肉、魚與海鮮，吸收情況通常較穩定。植物性鐵來源包括豆類、豆腐、深綠色蔬菜、全穀與強化食品，搭配芭樂、奇異果、柑橘、甜椒或番茄等維生素 C 食物，有助於非血基質鐵的利用。茶與咖啡中的成分、鈣與部分植酸，可能影響同一餐鐵的吸收，已知缺鐵者可把茶咖啡與主要含鐵餐錯開，健康者則無需避開茶或乳品。

要確認鐵是否不足，常會依情況檢查血球、血紅素、血清鐵、鐵蛋白與其他指標，女性還要問月經量，成人要留意腸胃道出血。鐵劑有噁心、腹痛、便祕等問題，高劑量也可能造成中毒，家中有幼兒時更要鎖好。NIH ODS 的鐵資料可供查對食物、缺乏風險、補充品與交互作用。[NIH ODS：Iron](https://ods.od.nih.gov/factsheets/Iron-HealthProfessional/)

## 碘、鋅、硒與微量礦物質，從食物多樣性開始

微量礦物質的需要量較少，作用卻很具體。碘是甲狀腺荷爾蒙的一部分，會影響代謝調節。含碘鹽、海鮮、蛋與乳品可提供來源，海藻或碘錠的劑量差異很大，甲狀腺疾病、孕期與哺乳期要個別評估。國民健康署的第八版 DRIs 專區提供碘、鈣、鐵、鎂、鉀與鈉的台灣資料，精確數值應依年齡與生理狀態查表。[國民健康署：國人膳食營養素參考攝取量第八版](https://www.hpa.gov.tw/Pages/Detail.aspx?feature=featurea02&nodeid=4248&pid=12285)

鋅參與酵素、蛋白質與遺傳物質合成，也和味覺、傷口修復及免疫功能有關。牡蠣、海鮮、肉類、乳品、豆類、堅果與全穀都能提供鋅。長期高劑量鋅錠可能造成噁心，也可能干擾銅的利用。硒參與抗氧化酵素與甲狀腺功能，缺乏與過量都需要留意，保健品不能被當成預防癌症的保證。氟化物與牙齒再礦化及蛀牙預防有關，錳、銅、鉬與鉻也各有生理作用，日常多樣飲食通常比自行疊加多種單方錠更穩妥。

## 怎麼安排每天都吃得到鈣來源？

把鈣分布在餐食，比每天睡前才想起一顆鈣片更容易持續、益處更多。建議先盤點三天飲食，再找出一個可替換的位置。下表是依據生活作息建議，不代表固定份量。

| 時段 | 一個容易執行的組合 | 讀標示時看什麼 |
| --- | --- | --- |
| 早餐 | 牛奶、優格或無糖加鈣豆漿，搭配蛋與全穀 | 鈣、蛋白質、添加糖 |
| 午餐 | 豆腐或小魚搭配青菜，主菜保留肉、魚、蛋或豆製品 | 豆腐是否使用鈣鹽，便當鈉量 |
| 下午 | 原味優格或一小份堅果，視全天熱量安排 | 糖、鈣與實際份量 |
| 晚餐 | 青江菜、芥藍、花椰菜、豆製品與適量蛋白質 | 鈣來源與醬料鈉量 |
| 不喝乳品 | 加鈣豆漿、鈣鹽豆腐、小魚連骨、深綠色蔬菜交替 | 植物奶要看鈣是否真的有強化 |

乳糖不耐受可嘗試優格、起司、無乳糖乳品或分次少量使用。乳品過敏、純素、吞嚥困難、腎臟病與食物攝取量很少的人，安排方式要個別設計。鈣片也要看成分、元素鈣含量、用藥時間與腎結石風險，不能用品牌名稱判斷安全。

## 骨質疏鬆能靠生活習慣降低風險嗎？

答案是可以降低部分風險，卻不能保證避開骨折。骨骼是活的組織，年輕時累積的骨量、年齡、荷爾蒙、家族史、體重變化、活動量、吸菸、酒精、飲食與藥物，都會影響後續骨骼狀況。骨鬆常安靜發展，等到跌倒或輕微碰撞後骨折才被發現。

| 風險或保護面向 | 可採取的行動 | 需要專業評估的情況 |
| --- | --- | --- |
| 鈣、維生素 D、蛋白質不足 | 每餐安排蛋白質，讓鈣來源分散在一天 | 食慾差、體重下降、吸收不良 |
| 久坐、肌力弱、平衡差 | 依能力做走路、阻力與平衡活動，從安全難度起步 | 跌倒史、骨折史、嚴重關節或神經疾病 |
| 吸菸、酒精過量 | 尋找戒菸與減酒支持 | 已有肝病、成癮、情緒或睡眠問題 |
| 偏瘦或快速減重 | 先保留蛋白質與總熱量，再談減重 | 飲食失控、術後、體重快速下降 |
| 長期使用類固醇等藥物 | 主動告知醫師並討論骨骼監測 | 長期用藥、月經提早停止或荷爾蒙異常 |
| 年齡、家族史或停經後風險 | 詢問是否需要骨密度檢查與跌倒評估 | 曾有脆弱性骨折或身高明顯變矮 |

美國預防服務工作小組 2025 年建議，65 歲以上女性接受骨質疏鬆篩檢，停經後未滿 65 歲女性若有風險，也先做風險評估再決定是否以 DXA 測量骨密度。這是美國預防建議，台灣讀者仍應依本地醫療院所、年齡、病史與家族風險判斷。[USPSTF：Osteoporosis Screening](https://www.uspreventiveservicestaskforce.org/uspstf/document/ClinicalSummaryFinal/osteoporosis-screening)

高齡者的骨折預防還要把防跌倒放進來。肌力、平衡、視力、鞋子、夜間照明、浴室扶手與家中動線，常比再買一瓶保健品更能直接改變風險。CDC 的高齡活動建議包含有氧、肌力與平衡活動，實際強度要配合個人的疾病與能力。[CDC：What Counts as Physical Activity for Older Adults](https://www.cdc.gov/physical-activity-basics/adding-older-adults/what-counts.html)

## 補充品常見錯誤：高劑量、重複與自行混搭

| 常見做法 | 風險 | 改法 |
| --- | --- | --- |
| 覺得疲倦就補鐵 | 可能延誤出血、感染或其他病因，過量也有毒性 | 先檢查，再由專業人員決定劑量 |
| 鈣片、綜合維生素、胃藥一起吃 | 成分重複，鈣也可能影響部分藥物吸收 | 帶著所有藥品與保健品清單詢問 |
| 腎臟病使用低鈉鹽 | 鉀含量可能造成高血鉀 | 先確認腎功能與用藥 |
| 用海藻粉補碘 | 碘含量差距大，甲狀腺疾病者可能受影響 | 看產品標示，必要時先驗證需求 |
| 覺得天然就能長期高劑量吃 | 天然來源也可能過量，補充品品質與劑量差異更大 | 以食物為主，補充品有明確目的與期限 |
| 用血鈣推論骨頭一定健康 | 血鈣調節與骨密度是不同問題 | 依骨密度、骨折風險與醫師評估判讀 |

### 何時要找醫師或營養師？

有以下狀況，請把喝水與礦物質問題交給醫療團隊處理：

- 持續嘔吐、腹瀉、發燒、無法進食或幾乎沒有尿。
- 意識混亂、昏厥、抽搐、嚴重頭痛、胸悶或心悸。
- 不明原因疲倦、臉色蒼白、黑便、血便、月經量明顯增加。
- 曾有低鈉、高血鉀、腎功能異常、心臟衰竭、肝硬化或透析。
- 懷孕、哺乳、兒童、高齡失智、吞嚥困難或需要限水。
- 曾發生輕微碰撞就骨折、身高變矮、背痛持續，或長期使用類固醇。

### Kat Chang 營養師的判讀

水和礦物質這部分可以分成三個重點。

水分先看安全與情境。辦公室久坐、戶外工作、長時間運動、發燒腹瀉與心腎疾病，喝水策略完全不同。對一般健康成人，補充水分是日常基礎，分次飲用比追逐某個目標數字有用。對限水者，少喝或多喝都可能帶來風險，應以醫囑為準。

礦物質先回到食物與症狀背後的原因。鈣、鎂、鉀、鐵、碘、鋅與硒各自有功能，補充品的標籤也常藏著重複劑量。綜合評估三天飲食、用藥、保健品、症狀與檢驗結果，才有機會找到真正需要調整的地方。

骨骼保養從年輕就開始，到了高齡階段仍能做風險管理。每天有鈣來源、吃得到蛋白質、維持活動與肌力、減少吸菸與酒精、處理跌倒危險，這些事情看似很普通，卻比單一神奇食物更值得你做。若已有骨質疏鬆或脆弱性骨折，營養要跟治療計畫一起安排，不能取代藥物與醫療追蹤。

## FAQ：章節主題常見問題

### Q1：每天一定要喝 2000 ml 的水嗎？

沒有適用所有人的單一數字。飲品、食物水分、氣溫、流汗、活動、年齡、疾病與藥物都會改變需求。健康成人可用國民健康署 6 至 8 杯水的建議做生活起點，再依情境調整。心臟、腎臟、肝臟疾病或醫師交代限水者，依個人計畫執行。

### Q2：瓶裝水一定比自來水好嗎？

包裝形式本身不代表營養或安全性一定較高。應看來源、合格標示、保存、開封後使用時間與飲用環境。需要礦物質時，也要看產品標示，不能只看「礦泉水」三個字。

### Q3：喝咖啡會讓身體脫水嗎？

咖啡含有水分，咖啡因也可能影響排尿與睡眠。一般人應把重點放在總量、個人反應、糖與奶精，以及是否因喝咖啡而少喝水。心悸、焦慮、睡眠差、孕期或有特定疾病者，請個別確認攝取量。

### Q4：覺得疲倦就吃鐵劑，會比較快恢復嗎？

疲倦單獨出現，無法證明缺鐵。月經量、飲食、腸胃道出血、慢性病與檢驗結果都要一起看。鐵劑應在確認需求後使用，並放在幼兒拿不到的地方。

### Q5：吃鈣片就能預防骨質疏鬆嗎？

鈣是骨骼所需營養素，單靠鈣片不能處理所有骨折風險。骨骼需要鈣、維生素 D、蛋白質、活動、肌力、平衡與適當醫療評估。已有骨質疏鬆、骨折史或長期用藥者，應詢問是否需要 DXA、藥物或營養補充。
