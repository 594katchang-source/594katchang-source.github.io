# 營養搶答對戰

中高齡友善的 QR Code 進場搶答遊戲。學生輸入名字後會隨機分成紅隊或藍隊，選擇三種模式之一開始對戰。

## 模式

- 第一模式：食物分類，依台灣食物代換表常用六大類設計題目。
- 第二模式：食物份量，依國健署「我的餐盤」口訣設計題目。
- 第三模式：彩虹食物，練習全穀雜糧、蔬菜、水果的多色選擇。

## 資料來源

- Google Drive 最新相關教案：`【115單場團衛】教案-我的餐盤健康吃，代謝與肌少遠離我.pdf`，建立時間 2026-05-05。
- Google Drive 最新相關簡報：`我的餐盤-標準教學簡報.pdf`，建立時間 2026-05-05，更新時間 2026-02-20。
- 衛生福利部國民健康署「我的餐盤」均衡飲食圖像及口訣。

## 使用方式

直接開啟 `index.html` 即可遊玩。發布到 GitHub Pages 後，頁面右上角「顯示 QR」會用目前網址產生 QR Code。

## 目前版本限制

這是 GitHub Pages 可部署的純前端版本，適合投影或單一裝置主持搶答。若要多位學生手機即時同步同一場比分，需要再接即時資料庫服務。
