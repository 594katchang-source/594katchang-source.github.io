# 飲食小偵探 ｜ 食物分類大挑戰 互動教具交付說明

## 專案概述
- **教具名稱**：飲食小偵探 ｜ 食物分類大挑戰
- **路徑**：`teach/food-detective/`
- **資料來源**：衛福部國民健康署最新食物代換標準表（收錄 368 筆標準食材）
- **主要特色**：
  1. **雙模式整合**：
     - **🖥️ 大螢幕線上互動模式**：投影課堂破冰、點擊標記（⭕ / ✕ / 空白）、即時計分與詳解、底部雙重認知數量盤點題。
     - **📄 A4 學習單產生器模式**：自選出題類別、4x4 到 5x6 網格排版、支援直接列印（`window.print()`）與下載高畫質 PDF（`html2canvas` + `jsPDF`）。
  2. **自選出題引擎**：
     - 🌾 全榖雜糧類專題
     - 🥩 豆魚蛋肉類專題
     - 🥬 蔬菜類專題
     - 🍎 水果類專題
     - 🥛 乳品類專題
     - 🥜 油脂與堅果種子類專題
     - ⚔️ 雙類對抗（全穀 vs 豆魚蛋肉、蔬菜 vs 水果）
     - 🚦 健康紅綠燈（天然原態未精製 vs 高油糖超加工製品）
  3. **位置**：
     - 已掛載於 `teach/index.html` 之「2. 教學互動」第一順位卡片。
