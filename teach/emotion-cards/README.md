# 草木心語 情緒覺察卡互動網站

## 上傳方式

把整個 `emotion-cards` 資料夾上傳到 GitHub repo `info` 的根目錄。

完成後網址：

https://594katchang-source.github.io/teach/emotion-cards/

## 檔案結構

```text
emotion-cards/
├── index.html
└── assets/
    ├── 01-lavender.webp
    ├── 02-chamomile.webp
    └── ...
```
